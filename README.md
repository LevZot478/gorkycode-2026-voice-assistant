# GORKYCODE 2026 — голосовой ассистент задач и встреч

Прототип для управления задачами, напоминаниями и встречами на русском языке. Пользователь пишет сообщение или записывает голос, приложение распознаёт намерение, создаёт запись, показывает расписание или находит сохранённое событие.

**Репозиторий:** https://github.com/LevZot478/gorkycode-2026-voice-assistant  
**Временное веб-демо:** https://special-trout-7vq96xxj45wvhpppv-8501.app.github.dev/

> **Важно:** демо работает, только пока запущен соответствующий GitHub Codespace и Streamlit на порту 8501. После остановки Codespace ссылка недоступна. Перед показом жюри запустите приложение и проверьте доступ по ссылке в другом браузере. Это не круглосуточный хостинг.

## Быстрый старт — бесплатно, без API-ключей

**Рекомендуемый способ для команды и проверки проекта:** GitHub Codespaces. Не нужен локально установленный Python, платный сервер, аккаунт GigaChat, Supabase или VPN для запуска кода внутри Codespaces. Нужен доступ к GitHub; бесплатность ограничена доступной квотой аккаунта.

### Первый запуск в Codespaces

1. Откройте [репозиторий](https://github.com/LevZot478/gorkycode-2026-voice-assistant).
2. Нажмите **Code → Codespaces → Create codespace on main**. Если предлагается конфигурация машины, выберите **2 cores**.
3. Дождитесь открытия онлайн-редактора VS Code. Внизу откройте **Terminal / Терминал**.
4. Выполните команду:

   ```bash
   bash scripts/start_free_demo.sh
   ```

   Скрипт установит Python-зависимости, при необходимости Ollama, скачает модель **Qwen3:1.7b** и запустит Streamlit. Для голоса используется **faster-whisper tiny**. AI-ключи не требуются.

5. Успешный запуск означает, что терминал показывает:

   ```text
   You can now view your Streamlit app in your browser.
   Local URL: http://localhost:8501
   ```

6. В панели снизу откройте **Ports / Порты**, найдите **8501**. Нажмите правой кнопкой по строке порта и выберите **Port Visibility → Public**.
7. Нажмите на появившуюся HTTPS-ссылку в столбце **Forwarded Address / Перенаправленный адрес**. Откроется интерфейс «Голосовой ассистент».

**Не останавливайте процесс в терминале**, пока нужен работающий сайт. Держать вкладку с редактором постоянно открытой необязательно, но сам Codespace должен оставаться запущенным. Если он остановится из-за тайм-аута, приложение и ссылка временно перестанут работать.

### Если Codespace уже создан (повторный запуск)

1. Откройте существующий Codespace через **Code → Codespaces**. **Не создавайте новый**, если старый сохранился: локальные события SQLite хранятся в его файловой системе.
2. Если в терминале ещё работает Streamlit, нажмите **Ctrl+C**.
3. Выполните:

   ```bash
   git pull origin main
   bash scripts/start_free_demo.sh
   ```

4. Снова проверьте **Ports → 8501 → Public** и обновите страницу сайта.

Если нужно только перезапустить приложение без обновления GitHub, достаточно второй команды.

### Почему стандартные запросы работают быстро

В бесплатном режиме скрипт включает `FAST_INTENT=1`. Однозначные распространённые формулировки обрабатывает локальный Python-парсер **без вызова LLM** — это уменьшает задержку на слабом CPU. Более свободные или сложные запросы переходят к **Ollama/Qwen3:1.7b** и могут выполняться заметно дольше. Таким образом, демо использует **гибридный разбор**, а не выдаёт все ответы за генерацию нейросетью.

Данные бесплатного демо сохраняются в SQLite внутри Codespace: `$HOME/.local/share/gorkycode/events.db`. Они переживают перезапуск приложения в **том же** Codespace, но могут быть потеряны после удаления Codespace. Сейчас события общие для всех посетителей публичной ссылки; используйте только вымышленные тестовые данные.

## Как проверить работу

Проверка основных сценариев (даты «сегодня/завтра» считаются по московскому времени, UTC+03:00):

| Сценарий | Пример команды | Ожидаемый результат |
| --- | --- | --- |
| Создание напоминания | «Напомни завтра в 10 позвонить Ивану» | Появляется напоминание с датой и временем |
| Создание встречи | «Добавь встречу с командой завтра в 15:00» | Встреча сохраняется и отображается в списке |
| Просмотр расписания | «Что у меня завтра?» | Появляются события за запрошенный день |
| Поиск старой записи | «Найди задачу про презентацию» | Находит подходящую **ранее созданную** запись |
| Голосовой ввод | Запишите одну из команд через микрофон | Речь переводится в текст, затем выполняется действие |

Для проверки поиска сначала создайте задачу «Подготовить презентацию завтра», затем найдите её. Для проверки сохранения перезапустите Streamlit в том же Codespace и снова посмотрите расписание. Первое голосовое сообщение может обрабатываться дольше, поскольку Whisper загружается при первом обращении.

### Возможности и ограничения

- Создание задач, напоминаний, встреч; получение событий за период; поиск по названиям.
- Веб-интерфейс с текстовым вводом, записью аудио, историей чата и списком ближайших событий.
- Для встречи с неполной датой/временем предусмотрен сценарий уточнения, однако его корректность для всех формулировок пока не гарантируется.
- В бесплатном режиме Qwen и Whisper работают на CPU: сложные запросы и распознавание голоса могут быть медленными.
- Бесплатный Codespace ограничен квотами GitHub, не предназначен для постоянной работы и может автоматически останавливаться. Для круглосуточной ссылки нужен другой хостинг.
- В прототипе нет авторизации пользователей и персонального разделения записей. Не вводите реальные телефоны, имена контактов и личные события.

## Что делать при ошибках

| Ситуация | Решение |
| --- | --- |
| По публичной ссылке написано «Страница недоступна» | Убедитесь, что Codespace **запущен**, Streamlit показывает `Local URL: http://localhost:8501`, а порт 8501 имеет видимость **Public**. |
| Сайт долго показывает «Думаю…» | Для стандартных фраз проверьте, что после обновления кода режим отображается как **«Быстрые команды + Ollama»**. Нестандартные запросы идут в локальную LLM и могут отвечать медленно. |
| После изменений GitHub сайт ведёт себя по-старому | Остановите Streamlit через **Ctrl+C** и запустите `git pull origin main`, затем `bash scripts/start_free_demo.sh`. |
| Установка Ollama сообщает `requires zstd` | Выполните `sudo apt-get install -y zstd` и снова запустите скрипт. В актуальном скрипте установка выполняется автоматически, когда Ollama ещё не установлена. |
| `apt-get update` выдаёт `NO_PUBKEY` для `dl.yarnpkg.com` | В образе Codespaces может быть проблема со сторонним репозиторием Yarn. Временно отключите **только** его источник APT (пример ниже), затем повторите установку. Не отключайте проверку подписей для всех репозиториев. |
| После перезапуска нет событий | Убедитесь, что открыли **тот же Codespace**. Новый Codespace использует отдельную SQLite-базу. |

Если мешает **Yarn GPG error**, выполните в терминале Codespaces:

```bash
sudo find /etc/apt/sources.list.d/ -maxdepth 1 -type f   -exec grep -l 'dl.yarnpkg.com' {} ;   | while read -r file; do sudo mv "$file" "$file.disabled"; done
sudo apt-get update
sudo apt-get install -y zstd
bash scripts/start_free_demo.sh
```

## Другие варианты запуска

### На своём компьютере

Требуется **Python 3.10+** (рекомендуется 3.11), Ollama и установленная языковая модель либо доступ к GigaChat API.

```bash
git clone https://github.com/LevZot478/gorkycode-2026-voice-assistant.git
cd gorkycode-2026-voice-assistant
python -m pip install -r requirements.txt
```

**Вариант A — без внешнего AI API:** запустите Ollama и скачайте модель:

```bash
ollama pull qwen3:1.7b
```

Для быстрой обработки стандартных команд установите переменные окружения `OLLAMA_MODEL=qwen3:1.7b` и `FAST_INTENT=1`. В Linux/macOS это можно сделать так:

```bash
export OLLAMA_MODEL=qwen3:1.7b
export FAST_INTENT=1
export WHISPER_MODEL_SIZE=tiny
python -m streamlit run app.py
```

На Windows переменные задаются через `$env:OLLAMA_MODEL = "qwen3:1.7b"` (PowerShell), затем запускается `python -m streamlit run app.py`. Сервер Ollama должен быть запущен отдельно. SQLite по умолчанию создаётся в `events.db`.

**Вариант B — с API Сбера:** настройте `GIGACHAT_AUTH_KEY` через локальный файл `.env` или переменные среды. Приложение использует GigaChat API и получает короткоживущий токен автоматически. Дополнительные переменные:

```dotenv
GIGACHAT_AUTH_KEY=your_authorization_key
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat-2
WHISPER_MODEL_SIZE=base
```

Получение ключа, условия доступа и оплата могут зависеть от учётной записи и тарифов Sber Studio / cloud.ru. Для GigaChat API требуется доверие к российским корневым сертификатам; см. [официальные инструкции по сертификатам](https://developers.sber.ru/docs/ru/gigachat/certificates). **Не отключайте TLS-проверку для API-запросов.** Альтернативный провайдер — Groq (переменная `GROQ_API_KEY`).

**База данных:** при наличии **обеих** переменных `SUPABASE_URL` и `SUPABASE_KEY`, если не задан `DATABASE_PATH`, используется Supabase. При отсутствии настроенного Supabase — SQLite. Заданная переменная `DATABASE_PATH` принудительно включает SQLite и задаёт путь к файлу. Для публичного прототипа необходимо отдельное тестовое хранилище без личных данных.

### Docker / российский хостинг

В репозитории есть `Dockerfile` и `amvera.yaml`. Можно развернуть приложение на совместимом Docker-хостинге, открыть порт **8501**, установить `APP_ENV=production` и настроить нужные секреты. Для этого режима нужен доступный сервер с достаточной RAM, рабочий LLM API и постоянное хранилище (Supabase либо постоянный диск, например `DATABASE_PATH=/data/events.db`). В Amvera это может быть платно. Данный способ **не нужен** для бесплатного временного демо.

## Архитектура проекта

```text
Браузер (текст или запись голоса)
  │
  ├── аудио → faster-whisper → распознанный текст
  ▼
app.py (Streamlit)
  ▼
ai.parse_intent()
  ├── FAST_INTENT=1 → быстрый парсер для типовых команд
  └── сложный запрос → Ollama / GigaChat / Groq
  ▼
backend.execute_intent()
  ▼
SQLite / Supabase
  ▼
Ответ и список событий в интерфейсе
```

**Основные модули:**

- `app.py` — веб-интерфейс, микрофон, чат и отображение событий.
- `ai/fast_intent.py` — быстрый разбор распространённых команд без LLM.
- `ai/intent.py` — выбор AI-провайдера, JSON-контракт, даты и обработка ошибок.
- `ai/transcription.py` — распознавание речи через faster-whisper.
- `backend/service.py`, `backend/database.py` — создание, хранение, выборка и поиск событий.
- `scripts/start_free_demo.sh` — бесплатный запуск в Codespaces.
- `.devcontainer/devcontainer.json` — настройки окружения Codespaces.
- `tests/` — тесты backend, AI-провайдера и быстрого разбора.

## Тестирование

```bash
python -m pytest -q tests
```

GitHub Actions выполняет компиляцию Python-файлов и тесты при обновлении `main` и при Pull Request. Тесты AI-провайдера используют подменённые HTTP-ответы; они **не подтверждают** доступность платного или внешнего API и не заменяют ручной тест через сайт.

## Безопасность и статус

- **Не публикуйте** API-ключи, `.env`, `.streamlit/secrets.toml` и реальные персональные данные в GitHub.
- У бесплатного демо **общая** SQLite-база для всех посетителей. Это учебный прототип, а не персональный защищённый календарь.
- Бесплатный запуск Codespaces и публикация порта проверялись вручную командой; постоянная доступность публичного адреса не гарантируется.
- GigaChat/Docker и облачный Supabase поддерживаются кодом как альтернативные конфигурации, но их фактическую доступность в конкретном окружении нужно проверять отдельно.
