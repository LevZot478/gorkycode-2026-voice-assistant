# GORKYCODE 2026 — голосовой ассистент задач и встреч

Веб-прототип для управления задачами и встречами с помощью обычного текста или русской речи. Проект для отборочного задания GORKYCODE 2026.

**Онлайн-демо:** ссылка появится после развёртывания и проверки.

## Что умеет

- Создавать задачи и напоминания: «Напомни завтра в 10 позвонить Ивану».
- Создавать встречи: «Добавь встречу с командой завтра в 15:00».
- Показывать расписание: «Что у меня на этой неделе?».
- Искать старые события: «Найди задачу про презентацию».
- Принимать голосовые сообщения и уточнять недостающую информацию.

## Технологии

- Python 3.10+, Streamlit — интерфейс и голосовой ввод.
- faster-whisper (модель `base` по умолчанию) — распознавание русской речи; модель загружается при первом голосовом запросе.
- Groq API — облачное понимание естественного языка при наличии `GROQ_API_KEY`.
- Ollama + Qwen3:4b — альтернативный локальный режим при отсутствии `GROQ_API_KEY`.
- Supabase — облачное хранение событий при наличии `SUPABASE_URL` и `SUPABASE_KEY`.
- SQLite — локальный режим и тесты.

## Архитектура

```text
Текст ──────────────────────┐
Аудио → faster-whisper ─────┤
                            ↓
                     Streamlit app.py
                            ↓
                   ai.parse_intent()
                     Groq / Ollama
                            ↓
                 backend.execute_intent()
                            ↓
                   Supabase / SQLite
                            ↓
                     Ответ в чате
```

## Локальный запуск

```bash
git clone https://github.com/LevZot478/gorkycode-2026-voice-assistant.git
cd gorkycode-2026-voice-assistant
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Для локального запуска с облачной моделью и Supabase создайте файл `.env`:

```dotenv
GROQ_API_KEY=your_groq_api_key
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your_supabase_key
WHISPER_MODEL_SIZE=base
```

**Не добавляйте `.env`, ключи и секреты в GitHub.** Без `GROQ_API_KEY` нужна запущенная Ollama с моделью `qwen3:4b` (адрес по умолчанию `http://localhost:11434/api/chat`). Без ключей Supabase используется локальная SQLite, не подходящая для постоянного хранения на эфемерном облачном хостинге.

## Публичный деплой: Streamlit Community Cloud

1. Откройте https://share.streamlit.io/ и создайте приложение из этого репозитория, ветка `main`, файл `app.py`.
2. В **Advanced settings → Secrets** добавьте:

```toml
GROQ_API_KEY = "your_groq_api_key"
SUPABASE_URL = "https://your-project.supabase.co"
SUPABASE_KEY = "your_supabase_key"
WHISPER_MODEL_SIZE = "base"
```

3. Дождитесь установки зависимостей, проверьте четыре текстовых сценария и голосовую запись.
4. Убедитесь, что записи сохраняются после перезапуска приложения. Добавьте проверенную публичную ссылку сюда и в заявку.

Для публичного демо используйте отдельную тестовую БД и ключ с минимально необходимыми правами: события в текущем прототипе не разделены по пользователям.

## Проверка

```bash
python -m pytest -q
```

Проверьте вручную создание задачи, создание встречи, просмотр периода, поиск, распознавание речи и сохранение после перезапуска. Автотесты backend не заменяют сквозной тест приложения.

## Структура

- `app.py` — Streamlit UI и обработка запросов.
- `ai/intent.py` — AI-разбор запросов.
- `ai/transcription.py` — распознавание речи.
- `backend/` — хранение, операции с задачами и встречами.
- `tests/` — тесты.
