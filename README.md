# gorkycode-2026-voice-assistant

AI voice assistant for task and meeting management (GORKYCODE 2026 qualification project).

## Features

- Add tasks
- Complete tasks
- List tasks
- Schedule meetings
- List meetings

## Quick start

```bash
python -m voice_assistant
```

Supported commands:

- `add task <title>`
- `complete task <id>`
- `list tasks`
- `schedule meeting <title> at <time>`
- `list meetings`
